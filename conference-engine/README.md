# Conference Engine

Browser-based VoIP / call-app simulator (Discord/Zoom/Skype/cell style).

Core behaviors:
- Bandwidth narrowing (stacked HP/LP)
- Packet loss + concealment (hold/mute/interp/repeat)
- Clock jitter (tiny delay wobble)
- Codec artifacts (bit depth + sample-rate reduction)
- Optional robot/stutter + noise gate + noise bed

Preview and WAV export share the same processing chain.
